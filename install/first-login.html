First login

The platform is ready when its Successful condition is True and status.version is the release:

kubectl -n koios get koiosplatform koios \
  -o jsonpath='{.status.version} {range .status.conditions[*]}{.type}={.status} {end}{"\n"}'

The address is in status.URL (the Route on OpenShift, or the Ingress host). The user is admin and its password is in the Secret <platform>-admin-password:

kubectl -n koios get secret koios-admin-password -o jsonpath='{.data.password}' | base64 -d; echo

Every service is reached through the gateway: the UI, and the APIs under /api/gateway/, /api/controller/, /api/eda/ and /api/galaxy/.

If the platform does not become ready, its conditions and the Failure message name the cause (Operate).

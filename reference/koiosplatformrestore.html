KoiosPlatformRestore

apiVersion: platform.koioss.com/v1alpha1 · kind: KoiosPlatformRestore

Fields of spec. Console says how the OpenShift creation form shows the field (form, advanced or hidden); fields without it are set in YAML. Objects marked open also accept the fields of the upstream resource they configure.

Field

Type

Values

Default

Console

Description

backup_dir

string

advanced: Backup Directory

Backup directory in the PVCs (if backup_name is not used).

backup_name

string

form: Backup Name

Source KoiosPlatformBackup (Successful). Alternative to backup_dir + backup_pvc.

controller

object

controller.backup_pvc

string

advanced: Controller Backup PVC

PVC of the controller component (if backup_name is not used).

deployment_name

string

form: New Koios Automation Platform Name

Destination KoiosPlatform, in the same namespace; it must not exist.

eda

object

eda.backup_pvc

string

advanced: EDA Backup PVC

PVC of the eda component (if backup_name is not used and the backup includes EDA).

gateway

object

gateway.backup_pvc

string

advanced: Gateway Backup PVC

PVC of the gateway component (if backup_name is not used).

hub

object

hub.backup_pvc

string

advanced: Hub Backup PVC

PVC of the hub component (if backup_name is not used and the backup includes Hub).

no_log

boolean

True

advanced: No Log Configuration

postgres_image

string

hidden: PostgreSQL Image

pg_restore client image (defaults to the platform PostgreSQL image); must be the server version or later.

postgres_image_version

string

hidden: PostgreSQL Image Version

Tag or sha256: of postgres_image.

spec_overrides

object (open)

advanced: Spec Overrides

Merged (recursively) with the spec of the backed-up KoiosPlatform.

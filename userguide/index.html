Automating with Koios Automation Platform

Learn how to use Koios Automation Platform functionality to scale and manage your automation. This guide assumes moderate familiarity with Ansible, including concepts such as Playbooks, Variables, and Tags.

This guide applies to the latest version of Koios Automation Platform only. The content in this guide is updated frequently and might contain functionality that is not available in previous versions. Likewise content in this guide can be removed or replaced if it applies to functionality that is no longer available in the latest version.

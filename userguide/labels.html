18. Labels

Labels are short names, such as env-dev or networking, that help organize templates, inventories and jobs. Each label belongs to an organization; the same name can exist in more than one organization. Labels do not grant access to resources.

18.1. Managing labels

Open Automation Execution > Templates and choose Create template > Create job template or Create template > Create workflow job template, or edit an existing template. In Labels, select an existing name or enter a new one. Submit with Create job template or Create workflow job template; when editing, use Save job template or Save workflow job template. See Job Templates for job template fields.

Inventories also have a Labels field in their create and edit forms under Automation Execution > Infrastructure > Inventories. It is available for standard and constructed inventories, but not smart inventories.

Labels on a template are copied to its jobs at launch; templates that prompt for labels can also accept launch-time labels. Jobs have their own label associations. Removing a label from a template does not remove it from jobs that already ran. A label can remain in use by another template, inventory, job, schedule or workflow node; removing it from one resource does not delete those other associations.

There is no separate Labels page. Manage labels on the resources that use them.

18.2. Grouping and filtering with labels

Labels provide flat groupings rather than folders. A resource can have several labels. Use names such as env-dev and team-networking to describe independent groupings.

In Automation Execution > Templates or Automation Execution > Jobs, choose Labels in the filter toolbar, then select label names. Selecting several names requires all of them to match. This filter matches exact names, not substrings: dev does not match dev-east. It filters by name rather than organization, so labels with the same name in different organizations can match resources you are allowed to see.

For inventory filtering by label, use the controller API, for example /api/controller/v2/inventories/?labels__name=env-dev. The inventory list does not provide the same dedicated Labels selector as Templates and Jobs.
